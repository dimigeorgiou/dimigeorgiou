# Hi 👋 I am Dimitrios

**Senior Machine Learning Engineer** 👨🏽‍💻 focusing on **Bioinformatics** 🧬

I've been coding since 2015. What pulled me toward bioinformatics was the sheer amount of biological data out there and how much ML can do with it. Today I build production AI systems in industry and research multi-modal AI for precision medicine in my PhD. I'm broadly interested in AI systems that are accurate, interpretable, and reliable enough for real clinical use.
